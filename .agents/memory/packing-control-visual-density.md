---
name: Shop-floor visual density
description: Visual direction for the Packing Control Board's desktop operational screen.
---

The Packing Control Board should retain a dense, screen-at-a-glance desktop layout: restrained outer padding, compact KPIs and controls, four visible work columns, a compact readiness legend, and a narrow order-details drawer.

**Why:** The approved reference is designed for a packing-floor display where a supervisor should see all key work states and the details panel at once on a 1024×768 screen.

**How to apply:** When adjusting desktop presentation, preserve the compact hierarchy and fit the main queue, its controls, and the legend within the viewport. Avoid reverting to oversized cards, generous dashboard whitespace, or a drawer that covers most of the board.
